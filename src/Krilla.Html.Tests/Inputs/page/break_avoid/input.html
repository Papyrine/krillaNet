First

Kept with the section below it

The heading above carries break-after: avoid, so the page may not begin at this paragraph. The break moves to the heading's own top edge instead and the two travel together, which is the whole point of the property: a heading stranded at the foot of a page is the thing every print stylesheet is written to prevent.

Second

Free to be stranded

This heading has no constraint on it, so the page begins here and the heading stays behind at the foot of the sheet before. It is the control: without it an implementation that moved every break away from every heading would pass.
