Anything after the table carries no column headings, the table having ended. The rule is the table's own extent rather than the page count: a header repeats while there is still a row of its table to label, and stops the moment a page begins past the last one. This paragraph is long enough to run onto a sheet of its own, which is the sheet that says so — it carries no heading row, and a converter that repeated the header for as long as the document lasted would put one there. The intervening text exists only to take up the room that makes the third page necessary, and says nothing else worth reading. It runs on a little further so that the break inside it leaves several lines on either side, which keeps the page boundary out of the reach of the orphan and widow counts a browser applies by default and leaves the heading row as the only thing this page has to say.
